# Version Control Guide

Version control records every single change made to the project. This allows the team to see 
who changed what, when, and why. It also allows them to go back to an older version if needed.


## What Is a Branch?

A branch is a separate copy of the project where you can work on it without altering the main branch.


## Commit, Push, Pull Request
A commit saves a version of your changes and has a clear message of what was altered. A push uploads your commits to GitHub. A pull request asks the team to review the branch before merging it into the main branch.
